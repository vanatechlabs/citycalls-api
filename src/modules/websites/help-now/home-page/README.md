# HelpNow home page

HelpNow-only home-page sections, kept separate from City Calls and Beauty &
Salon even when section names match.

`helpNowHome.*` holds four sections — `hero`, `marquee`, `about` and
`services` — one document each in `helpNowHomeSections`, edited from
Admin → Website Section → Help Now. Defaults (the site's original content)
are in `helpNowHome.defaults.ts`; the website reads everything at once from
`GET /public/websites/help-now/home-page`.
